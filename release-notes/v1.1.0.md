# Parallels Manager 1.1.0

Parallels Manager is a Mac app for running your Parallels Desktop virtual machines by keyboard
and with VoiceOver. It lists your VMs, starts, stops, pauses, clones and deletes them, and makes
new Windows 11 and Ubuntu VMs without any installer questions.

## Added

- **New Ubuntu VM** (File, New Ubuntu VM…, Command-Option-N). Give the VM a name, your Ubuntu
  user name and password, and choose its processors, memory and disk size. Parallels Manager
  downloads Ubuntu 26.04 LTS (about 6 GB the first time, then kept) and installs the full desktop
  with no questions, while Terminal shows how it's going. It takes 15 to 40 minutes. When it's
  done, a snapshot of the fresh install is taken and the VM starts. Terminal then gives its
  address and the command to reach it over SSH. You can choose:
  - **Orca screen reader on from the start**, at the login screen and after.
  - **Sign in automatically.**
  - **Backtick key is Caps Lock.** macOS keeps the real Caps Lock for itself, so the backtick
    key (above Tab) becomes Caps Lock inside Ubuntu, and Orca uses Caps Lock as its Orca key.
    The VM then can't type a backtick or tilde.
  - **sudo without a password**, handy if you set the VM up over SSH.

  The VM also gets your Mac's time zone and SSH keys. New Ubuntu VM needs Parallels Desktop Pro
  or Business, and two Homebrew packages: `brew install xorriso openssl`.
- **Processors, memory and disk size** in both New VM dialogs, as three pop-up menus after the
  name. Memory always leaves your Mac at least 4 GB for itself. New Windows VM starts at 6
  processors, 8 GB and 128 GB; New Ubuntu VM at 4 processors, 6 GB and 64 GB. Both start lower
  on a smaller Mac.
- **Remove from List** (VM Actions menu, the VM's context menu, or VoiceOver's actions with
  VO-Command-Space). This is for a VM whose files are gone, for example moved to the Trash
  outside Parallels. Parallels lists such a VM but can't start or delete it, and Parallels
  Manager now shows it as "Invalid (files missing)" rather than "Unknown". Removing it only
  makes Parallels forget it; any files that remain are left alone. Clone and Delete aren't
  offered for it, because they can't work.

## Changed

- **Command-N opens New Windows VM.** It used to open a second Parallels Manager window, because
  a built-in New Window command had the same key. The File menu now has New Windows VM… and New
  Ubuntu VM….
- **It's signed and notarized by Apple,** so it opens normally the first time, with no trip to
  System Settings.

## Fixed

- **VM names are read and shown exactly.** They had spaces in front ("   Windows 11 ARM"), and a
  name with two spaces in it had them run together.
- **Tab moves through the New Windows VM dialog.** Opened from the File menu, Tab used to stay
  in the name field.

## Reporting Issues

Found a problem or have an idea? Please

problem with New Ubuntu VM or New Windows VM, paste what Terminal showed. Or email

## Downloads

**ParallelsManager-1.1.0.dmg**: open it and move Parallels Manager to your Applications folder.
**ParallelsManager-1.1.0.dmg.sha256** is its checksum. The
[README](https://github.com/TheIdeaPlace/ParallelsManager#readme) describes everything Parallels
Manager does, with every keyboard shortcut.

## Requirements

- A Mac with Apple silicon and macOS 14 Sonoma or later.
- Parallels Desktop. To make new VMs: Parallels Desktop Pro or Business, and the Homebrew
  packages above (New Windows VM's are listed in the README).
